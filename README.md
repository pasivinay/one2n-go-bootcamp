# **Go Bootcamp**

## **Logic Building - Basics**

This repository contains fundamental Go functions to strengthen logic-building skills. The package `basics` located at `exercises/logic_building/basics` includes various utility functions with corresponding test cases for validation.  

### **Requirements**

1. Go

### Instructions

1. Clone the repository and change directory to exercises/logic_building/basics:
    ```bash
    git clone https://github.com/pasivinay/one2n-go-bootcamp.git
    cd ./exercises/logic_building/basics
    ```

2. Run the tests :
    ```bash
    go test
    ```


###  Functions Included  

### `1. EvenOdd(n int) bool`  
Determines whether a given integer is even (`true`) or odd (`false`).  

### `2. Table(n int) string`  
Generates a multiplication table for the given integer.  

### `3. Sum(n int) int`  
Computes the sum of the first `n` natural numbers.  

### `4. Swap(a, b int) (int, int)`  
Swaps the values of two integers and returns them.  

### `5. ClosestNumber(n, m int) int`  
Finds the number closest to `n` that is divisible by `m`.  

### `6. OppOfDice(n int) int`  
Returns the number on the opposite face of a standard six-sided die.  

### `7. NthTermOfAP(a, b, n int) int`  
Computes the `n`th term of an arithmetic progression given the first two terms.  

## Additional Information  

- The functions are designed for fundamental problem-solving in Go.  
- Test cases are provided to validate the correctness of each function.  
- This repository serves as a reference for learning Go syntax and control structures.
